# Aakshant Kumar — Portfolio

Welcome to the complete works of Aakshant Kumar. 

I’m a third-year AI engineering student at CSJM University, founder of the hackathon squad Void Walkers, and VP Tech at Kaiketsu Tech. My work bridges the gap between deep learning and production software—from training domain-specific models like DistilBERT to shipping the Next.js apps that put them in users' hands.

This portfolio is a living archive of my builds in PyTorch, Next.js, and agentic AI. It's presented as a four-part manga journey—from a gamer, to an AI researcher, to an agency co-founder—using a distinct monochrome ink aesthetic.

## Features

- **The Journey (Arcs)**: My professional and academic history structured into manga "arcs" (आरंभ पर्व, दल पर्व, जागरण पर्व, क्षितिज पर्व) displaying projects, hackathons, and skills unlocked over time.
- **Complete Works (Side Quests)**: A dedicated section for smaller experiments, client builds, Kaggle competitions, and proofs of concept.
- **Manga Aesthetic**: Designed entirely around a high-contrast ink-and-paper motif, featuring authentic typesetting details, Devanagari lettering, and custom SVG panel filters.
- **Dynamic Interactions**: Features micro-animations, liquid carve effects, and canvas-based pixel reveals as you navigate the boards.

## Tech Stack

The project is built entirely from the ground up prioritizing premium craft, fine-tuned performance, and motion over standard templates.

### Core
- **Next.js 16** (App Router)
- **React 19**
- **TypeScript**

### Styling & Animation
- **Tailwind CSS v4**
- **Vanilla CSS / CSS Variables** (for structural layout scaling and non-repro blue guide lines)
- **Framer Motion** (for liquid physics and spring animations)
- **HTML5 Canvas API** (for the dynamic pixel-reveal interactions)
